# swift_k12_education
swift_k12_education is an intro Swift repository that contains 3 Swift files. Two_Game_Menu, OtherGameCode and RobotGameCode.
Two_Game_Menu is a simple selection menu featuring two games (coded as functions) called by the main. Uses user input to progress code.
OtherGameCode contains code for other possible game examples that can be copied and pasted in the game fucntions in Two_Game_Menu.
RobotGameCode is code for Swift Playground that features a simple tap to jump robot.
